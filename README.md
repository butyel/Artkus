# Artkus

Site institucional da Artkus, com Pilates, Osteopatia, Fisioterapia e Dermatofuncional.

## Estrutura

Site estático em HTML, CSS e JavaScript. Os arquivos ficam na raiz e os recursos visuais em `assets/`. Não há etapa de compilação ou dependências de execução.

## Desenvolvimento

Execute `python -m http.server 8000` na pasta do projeto e abra `http://localhost:8000`.
